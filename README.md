# 領収書管理（GAS）

領収書の撮影から、OCR、勘定科目とインボイスの判定、ファイルの仕分け、弥生会計用CSVの出力までを行う。
スプレッドシート「経費管理」に紐づけたApps Script（コンテナバインド）として動かす。

| 道具 | 役割 |
|---|---|
| 撮影アプリ（`?page=camera`） | 利用者を選んで撮影する。画像は未処理フォルダに入り、OCRが自動で動く |
| スプレッドシート | 入力とデータの保管。計上会社・用途・精算月を入れ、チェックして「確定する」 |
| 管理アプリ | 精算額、会社別の計上額と残金、CSVのZIPダウンロード、科目の判定が当たった割合 |

## ファイル

| ファイル | 内容 |
|---|---|
| `Main.js` | 定数、列の定義、メニュー、`doGet` |
| `Schema.js` | 初期設定（シート作成、入力規則、初期値） |
| `Master.js` | 設定とマスタの読み込み |
| `Logic.js` | 判定額・科目・税区分・期・CSV行の計算（GASのサービスを使わない） |
| `Receipts.js` | 入力時の再計算（`onEdit`）、確定、科目の学習 |
| `Capture.js` | 画像の保存、Gemini によるOCR、未処理フォルダの取り込み |
| `Admin.js` | 管理アプリ用のデータ取得、CSV出力 |
| `Auth.js` | 利用者の確認、監査ログ |
| `admin.html` `camera.html` `Stylesheet.html` | 画面 |
| `tests/` | `node tests/logic.test.js` `node tests/flow.test.js` |

## セットアップ

1. スプレッドシート「経費管理」で「拡張機能 > Apps Script」を開き、スクリプトIDを控える。
2. `.clasp.json.example` を `.clasp.json` にコピーし、`scriptId` を入れて `clasp push` する。
3. Apps Script の「プロジェクトの設定 > スクリプト プロパティ」に `GEMINI_API_KEY` を登録する。
4. スプレッドシートを再読み込みし、メニュー「領収書管理 > 初期設定（シートを作成）」を実行する。
5. マスタを入力する。
   - 会社マスタ：期首月と第1期の開始年は初期値として入っている。年間予算（任意）を入れる
   - 利用者マスタ：弥生の補助科目（CSVの貸方補助科目）
   - 設定：開始No（既存の続きから採番する場合）、インボイス有の税区分名（8%）
   - 税区分マスタ：8%の税区分名
6. 「デプロイ > 新しいデプロイ > ウェブアプリ」で公開する（実行ユーザー：自分、アクセス：組織内）。
7. メニュー「アプリのURLを表示」で、管理アプリと撮影アプリのURLを確認する。

`_管理者` シートにメールアドレスを入れると、その人だけが使えるようになる。空のあいだは組織内の全員が使える。

## 保管先

- 未処理：設定の「未処理フォルダID」
- 確定後：保管フォルダ / 会社フォルダ / 期（例：`第12期`）/ `No_日付_店名_金額.jpg`
- 期は領収書日付と会社マスタの期首月で決める。期首月が未設定の会社は、会社フォルダの直下に入る。

## 判定のルール

- 科目：同じ店の過去の科目（学習）→ キーワードのルール → Geminiの推定 の順。確定時に店名と科目を「科目ルール」へ記録する。
- 飲食費：税抜経理。控除できない消費税を含めた判定額 ÷ 人数 が基準額以下なら少額交際費または会議費、超えれば交際費。人数が空白なら判定額そのもので判定する。
- インボイス無し：領収書日付で控除割合と税区分名を切り替える（税区分マスタ）。
- 人が直した科目は、その後の再計算で上書きしない。

## 本番で確認が必要な点

- CSVの列（`Logic.js` の `yayoiRow_`）は弥生会計の標準25項目で作っている。現行のCSVと項目の値が同じか、1か月分を見比べること。
- 税区分名（インボイス有の10%・8%、インボイス無しの8%）は設定シートの値をそのまま出力する。
- スマホでカメラが起動しない場合は「写真を選ぶ」から撮影する。
